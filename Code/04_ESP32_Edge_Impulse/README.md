# ESP32 with Edge Impulse

This folder contains the ESP32 source code integrated with the Edge Impulse machine learning model for waste classification.

## Features

- Integration of the Edge Impulse trained model
- Image classification using ESP32
- Identification of different waste categories
- Processing of model prediction results

## Waste Categories

- Plastic Waste
- Wet Waste
- Dry Waste
- E-Waste
